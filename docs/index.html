Play Portal: Revolution in virtual reality.

Free mod. Needs the game on Steam, a PC VR headset and SteamVR.

Download for Windows Setup (.exe) · finds the game itself Download for Linux ZIP · also for manual install on Windows

Version history

Enjoying the mod? It's free and won't get much further development, but a donation is a welcome thank-you for the work.

The setup isn't signed, so Windows SmartScreen can warn: click “More info”, then “Run anyway”. Windows Defender can flag d3d11.dll as a false alarm, see the README. Only download the mod from here or its GitHub page.

Getting started

  1. Windows: run the setup. Linux: extract the ZIP to steamapps/common/Portal Revolution.
  2. Start the game with SteamVR.
  3. Adjust the VR settings on the VR tab of the game's settings menu.

Features

  • Stereo view, head tracking, roomscale
  • Portals, smoke and glass render correctly
  • Menu as headset overlay: laser pointer or stick
  • Walking where the controller points; snap or smooth turning
  • Portal gun in your hand, shots from the muzzle
  • Chell's arms and hands follow your controllers
  • Press buttons by hand, pick up cubes
  • Chell has your body height and crouches with you
  • Left-handed and seated play
  • Comfort options against motion sickness
  • HUD, hints and subtitles in the headset
  • Controller vibration
  • VR tab in the game's settings, all languages of the game
